# MGDP Go2 AMP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a separate Go2 project that retains MGDP perception/control and uses a WMP-style adversarial motion reward in both MGDP terrain stages.

**Architecture:** Copy the minimal MGDP runtime into `MGDP_GO2_AMP`, then register two new Go2-only tasks. A 30-dimensional AMP state adapter and weighted trajectory loader feed a least-squares discriminator; a small optional hook in the existing MGDP runner adds style reward to its original PPO rollout and trains the discriminator separately. The original MGDP tasks and policy/world-model algorithms remain callable.

**Tech Stack:** Python 3.8, NumPy, PyTorch 1.10/CUDA 11.3, Isaac Gym, Warp, `unittest`.

**Spec:** `docs/superpowers/specs/2026-09-21-mgdp-go2-amp-design.md`

## Global Constraints

- Source projects `MGDP`, `WMP` and `amp_go2` are read-only; all product files go under `MGDP_GO2_AMP`.
- Only Go2 trains in the new tasks. Preserve MGDP's terrain classes, perception/world model, PPO objectives, curriculum, policy observations and control.
- Disable `motion_trot` and `feet_air_time` in both new tasks; retain MGDP's task and safety rewards.
- Stage 1 expert category weights are stance 0.10, translation 0.70, turn 0.20. Stage 2 weights are stance 0.10, forward 0.80, slow turn 0.10.
- The discriminator input is two consecutive 30-dimensional states: joint positions 12, body linear velocity 3, body angular velocity 3 and joint velocities 12.
- Default style coefficient is 0.01; terrain gates are 1.0 for Stage 1 classes 0–4 or Stage 2 classes 0–2, and 0.25 otherwise.
- Never sample expert transitions across clips or pair a policy terminal state with a reset state.
- Current Windows Python is 3.11 without `torch`; CPU tests that use PyTorch and Isaac Gym smoke tests must run in the documented compatible training environment. Run pure-data and syntax checks locally.

## Review Focus

1. One-frame or non-finite motion files should fail with the filename: tested in Task 2.
2. An unexpected Go2 DOF order should fail before rollout: tested in Task 4.
3. A done transition should use the state before reset: tested in Task 4 and Task 5.
4. A Stage 2 full resume without AMP state should fail clearly; explicit policy-only warm start should work: tested in Task 5.
5. A zero AMP coefficient or difficult-terrain gate should yield the specified total reward: tested in Task 3.

```python
AMP_COLUMNS = np.r_[7:19, 31:34, 34:37, 37:49]
if frames.ndim != 2 or frames.shape[1] != 61 or len(frames) < 2:
    raise ValueError(f"{path}: expected at least two 61-D frames")
if not np.isfinite(frames).all() or frame_dt <= 0 or (len(frames)-1)*frame_dt < dt:
    raise ValueError(f"{path}: invalid trajectory values or duration")
states = frames[:, AMP_COLUMNS].astype(np.float32)
maximum_start_time = (len(frames) - 1) * frame_dt - dt
start_time = rng.uniform(0.0, maximum_start_time, size=count)
start_position = start_time / frame_dt
next_position = (start_time + dt) / frame_dt
def interpolate(position):
    low = np.floor(position).astype(np.int64)
    high = np.minimum(low + 1, len(states) - 1)
    blend = (position - low)[:, None]
    return ((1.0 - blend) * states[low] + blend * states[high]).astype(np.float32)
return interpolate(start_position), interpolate(next_position)
```
